Pocket Rave

A pocket sized RGB light controller. Preview the three modes below, then explore the C++ sketch and wiring guide to build it with an Arduino Uno and a common cathode RGB LED.

Simulation paused. Press Start lights.

From screen to circuit

The physical build uses one RGB LED. The preview repeats it three times for visibility. A button cycles modes; a potentiometer sets 60–180 BPM. The sketch uses millis() so button input keeps responding while the LED animates.

ComponentConnection (Arduino Uno)
RGB LED red anodeD9 → 330 Ω resistor → red anode
RGB LED green anodeD10 → 330 Ω resistor → green anode
RGB LED blue anodeD11 → 330 Ω resistor → blue anode
RGB LED common cathodeGND
Momentary buttonD2 ↔ button ↔ GND (INPUT_PULLUP)
10 kΩ potentiometerOuter pins: 5V / GND. Wiper: A0

Use a separate resistor for each color channel. Check your LED's pinout. This sketch targets a common cathode LED; common anode LEDs need inverted outputs. Power from USB. Hardware has not been bench tested.
