Bring your own dataset

Required headers: Name, Author, User Rating, Reviews, Price, Year, Genre. Quoted fields and commas inside quotes are supported. File limit: 5 MB. Invalid rows are excluded and counted; exact duplicate rows are removed.

Common Amazon bestseller CSV exports use this schema. No Amazon dataset is bundled or scraped. Your CSV is processed in this browser and is not uploaded. The repository also includes a Python/pandas command line pipeline with matching validation.
